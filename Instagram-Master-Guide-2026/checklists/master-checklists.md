# Master Checklists for Instagram Success

Use these checklists to ensure every post and every day is optimized for growth.

## 1. New Account Checklist
- [ ] Username: Short, no symbols, niche-related.
- [ ] Name Field: Includes primary keyword (e.g., "John | AI Tips").
- [ ] Bio: Includes Hook, Value, Social Proof, and CTA.
- [ ] Profile Picture: High-contrast, brand color background.
- [ ] Account Type: Set to "Creator" or "Business."
- [ ] SEO: Keywords added to the "Topic" settings.

## 2. Viral Reel Checklist
- [ ] Visual Hook: Something moves in the first 0.5s.
- [ ] Verbal Hook: On-screen text addresses a pain point.
- [ ] Audio: Trending audio at 5% or niche-relevant audio.
- [ ] Captions: Auto-generated, high-contrast, center-screen.
- [ ] SEO Caption: First 5 words include primary keyword.
- [ ] CTA: One clear instruction in the last 2 seconds.

## 3. Daily Growth Checklist
- [ ] Post 1 Reel (High-retention).
- [ ] Post 3-5 Stories (Personal + Value + Engagement Sticker).
- [ ] Reply to every comment within the first 60 minutes.
- [ ] Engage with 5 large accounts in your niche.
- [ ] Check DMs and reply with voice notes where possible.

## 4. Weekly Optimization Checklist
- [ ] Audit top 3 posts: Why did they work?
- [ ] Audit bottom 3 posts: What failed?
- [ ] Batch-create 5-7 Reels for the next week.
- [ ] Update Broadcast Channel with an "Inner Circle" nugget.
- [ ] Check "Your Algorithm" topics to ensure niche authority.

## 5. Monthly Growth & Audit Checklist
- [ ] **Data Export:** Download Instagram Insights for the last 30 days.
- [ ] **Follower Conversion Audit:** (New Followers / Profile Visits) * 100. Goal: >2%.
- [ ] **Niche Re-evaluation:** Are there new trending sub-topics in my niche?
- [ ] **Collaboration Outreach:** Reach out to 5 creators for "Collab Posts" next month.
- [ ] **Monetization Review:** Which offer generated the most revenue? (Affiliate vs Digital Product).
- [ ] **Clean Up:** Archive low-performing posts that no longer match the brand aesthetic.

## 6. Instagram SEO Checklist
- [ ] **Keyword Density:** Primary keyword used in 100% of captions this week?
- [ ] **Alt Text Check:** Every post has manual, descriptive Alt Text?
- [ ] **On-Screen Text:** Keywords included in the first 3 seconds of Reels?
- [ ] **Audio SEO:** Are you using audio with keywords in the title?
- [ ] **Geotagging:** Using relevant city/location tags to reach local audiences?

## 7. Monetization Readiness Checklist
- [ ] **Bio Link:** Does it go directly to a high-converting landing page?
- [ ] **Lead Magnet:** Is the "Freebie" still relevant to the current content?
- [ ] **Story Highlights:** Are "Reviews" and "How to Buy" highlights up to date?
- [ ] **ManyChat Check:** Are all automated DM flows working correctly?
- [ ] **Media Kit:** Is your media kit updated with the latest reach and engagement stats?
